怎么读这本笔记

  • 从 01 开始；每篇顶部有「我带着的问题」和「读完能答的三个问题」
  • 答不出就回去重读那一节——答不出说明我没学会，不发
  • 照 7 天学习计划，每天读 2—4 篇 + 动手做 1 件真实小事

凭什么说它靠谱

  • 每条结论带源码路径 / 命令输出 / 日志数字，能复核
  • 每篇三样固定内核：判断演化、一手细节、承认错误或边界
  • 基于 developer preview，版本锚定 dsh 0.2.2-rc.1，过时了会标出来

这不是教程

这是一个还在学的人留下的路标：我先学会，才发出来；看不懂的地方，我写「我还没搞懂」。

学习笔记全部可复核持续迭代

适合谁
  • 用 Claude Code / Cursor，想知道差在哪
  • 装了 DSH，但卡在配置、插件、上下文
  • 想写插件，或想把它接进自己的工作流
不适合谁
  • 想找一篇官方文档翻译的人
  • 想找「最强 Agent 排行榜」的人
  • 指望它承诺收益的人
你会得到什么

一套能自己复现的判断：它是什么、怎么跑、哪里能改、什么时候别用。
